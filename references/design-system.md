# Дизайн-система презентаций «Финансовый директор | Мастер CFO»

Снято с эталонного деком эфира («Готовые промпты в DeepSeek и Qwen», 97 слайдов,
дизайнер школы). Это правила вёрстки, которым следуют все презы школы.

## 0. Формат

- 16:9, слайд 1280×720 px (печать 960×540 pt). Тёмная тема.
- Шрифт — **Montserrat** (заголовки 800/900, тело 400–600). Подключён в `theme.css`.

## 1. Палитра

| Роль                | HEX                                 | Где                                |
| ------------------- | ----------------------------------- | ---------------------------------- |
| Фон-база            | `#0B0D0A` (почти чёрный с зеленцой) | весь слайд                         |
| Фон карточек тёмных | `#151715`, прозрачность ~72%        | .card, .row-card                   |
| **Лайм-акцент**     | `#A8E84A`                           | заголовки, таблетки, цифры, иконки |
| Яркий лайм          | `#DCFF41`                           | пики, кнопки                       |
| Мятная бирюза       | `#64FEBE`                           | вторая в градиенте                 |
| Белый               | `#FFFFFF`                           | текст, белые карточки              |
| Приглушённый        | `#B9C2B5`                           | подзаголовки, подписи              |
| Красный (негатив)   | `#E5332A`                           | маркер «×»                         |

**Фирменный градиент:** лайм → бирюза (`95deg`). Только на ЗАЛИВКАХ фигур (таблетки, иконки-квадраты, кружки-цифры steps) — там он не даёт артефактов.
**Свечение:** radial-glow лаймом/бирюзой по углам слайда + тонкая контурная текстура + виньетка.

> **Градиент В ТЕКСТЕ (`background-clip: text`) — НЕ использовать.** В headless-Chrome при печати в PDF он оставляет тонкую линию-рамку по краю блока (тянется через весь слайд под заголовком и у крупных цифр). Заголовки и крупные цифры — СПЛОШНЫМ цветом (лайм / бирюза / белый).

## 2. Типографика

- **Заголовок** — UPPERCASE, Montserrat 800, 54px (крупный 72px), line-height ~1.04.
  Цвет: сплошной **лайм** (`.title`) или **бирюза** (`.title--teal`) или **белый** (`.title--white`). Сплошной, НЕ градиент-в-тексте (см. предупреждение выше — иначе линия-артефакт в PDF).
  Перенос строк — вручную через `<br>` (дизайнер контролирует ритм, обычно 2 строки).
- **Подзаголовок** — Montserrat 500, 24px, приглушённый `#B9C2B5`; ИЛИ в лаймовой «таблетке».
- **Тело** — 20–22px, белое, regular/medium. **Курсив** — для формул/цитат.
- **Подпункты списков** — лайм-bold заголовок + белый текст-пояснение под ним.

## 3. Сетка и композиция

- Левое выравнивание, крупный левый отступ (`--pad` 84px), заголовок в верхней трети.
- Контент-слайды: 1–2 колонки. Любимая раскладка — **текст слева + визуал/3D/скрин справа** (`.two`).
- Дивайдеры, оффер, финал — **по центру** (`.slide--center`).

## 4. Повторяющиеся компоненты (классы в theme.css)

- `.pill` — «таблетка»: скруглённая (999px) лаймовая/градиентная плашка с тёмным текстом. Категория, подзаголовок, № модуля. Со свечением.
- `.card` — тёмная стеклянная карточка (R26, тонкая обводка) — формулы, списки, блоки.
- `.card-white` — белая карточка (R20, тень) — скрины, отзывы, QR, визитки.
- `.badge` — иконка-квадрат (градиент) + заголовок (лайм uppercase) + текст.
- `.steps` — нумерованный список: лаймовые кружки-цифры + соединительная вертикальная линия. Для «шагов/что хорошо».
- `ol.plain` — плоский нумерованный список (программа курса), цифры лаймом.
- `.row-card` + `.mark--no/.mark--yes` — строка «маркер + таблетка-категория + текст». Система **good (лаймовый кружок) / bad (красный ×)**.
- `.wall` — масонри-сетка 3 колонки белых карточек (стена отзывов / соцдоказательство).
- `.obj` — плейсхолдер под 3D-объект/мокап (заменять на `<img>` с PNG дизайнера).

## 5. 3D-объекты и фон

- Крупные **глянцевые полупрозрачные зелёные 3D-объекты со свечением**: «!», «?», подарок,
  логотипы нейросетей, бумажные самолётики (telegram) на CTA. Это PNG-ассеты — кладём в `images/`
  и вставляем `<img>` в `.obj`-зону справа/по центру. CSS только имитирует glow на плейсхолдере.
- Фон: тонкие контурные/топографические линии + зелёный glow. В `theme.css` приближено градиентами.

## 6. Типовые слайды (есть в slide-templates.html)

1. Обложка — текст слева (заголовок + бейдж-подзаголовок) + 3D/мокап справа.
2. Секция-дивайдер — заголовок + таблетка + бейдж, крупный 3D-объект.
3. Список GOOD — `.steps` слева + скрин справа.
4. Список BAD — `.row-card` с красным × + лаймовая таблетка-категория.
5. Формула/цитата — тёмная `.card` с курсивом.
6. Программа курса — таблетка «Модуль N» + заголовок + `ol.plain` в карточке.
7. Стена отзывов — `.wall` из белых карточек.
8. Оффер/цена — центр, таблетка + крупная цена + старая цена зачёркнута.
9. Финал-CTA — центр, таблетка + заголовок + белые карточки (аккаунт + QR) + самолётики.

## 7. Свап под новый референс цвета

Менять ТОЛЬКО блок `:root` в `theme.css` (`--lime`, `--teal`, `--bg`, `--lime-br`).
Раскладка, типографика, компоненты остаются — это и есть единый стиль школы.
Если референс не зелёный (напр. синий) — подобрать акцент + вторую для градиента, фон оставить тёмным.
Под новый цвет: перебакать фоны (скрипт в `assets`, поменять LIME/TEAL) и генерить объекты с `--color`.

## 8. 3D-объекты (v2)

- Каждый смысловой слайд получает 3D-объект, подобранный по теме (`objects/manifest.json`, matching по keywords).
- Объекты — глянцевые, объёмные, со свечением, трендовые, НЕ плоские. Лайм/бирюза, прозрачный фон.
- Свечение-ореол + контактная тень **запечены прямо в PNG** (генератор `gen-3d.py`), CSS-фильтр на объект НЕ вешаем (иначе PDF растрируется и мерцает).
- Вставка: `<div class="obj-wrap"><img class="obj3d" src="objects/<key>.png"></div>` (модификаторы `.sm` / `.lg`).
- Генерация нового: `python3 gen-3d.py "<concept>"` или `--prompt "..."`; движок бесплатный Pollinations.ai, без ключа (фон убирается в прозрачность автоматически).
- Логотипы нейросетей / мокапы телефонов / скрины / фото / QR — это реальные ассеты в `images/`, не генерим вслепую.

## 9. Производительность (v2)

- Montserrat — локально (`fonts/` + `fonts.css`), не Google Fonts → нет мерцания (FOUT).
- Фон — запечённый `bg-corner.webp` / `bg-center.webp` (свечение+контур+виньетка), не живой CSS-градиент.
- Без `backdrop-filter` и без `filter: drop-shadow` на объектах → Chrome рендерит страницы вектором, PDF лёгкий (~0.3 МБ/слайд против 0.5+ с фильтрами).
