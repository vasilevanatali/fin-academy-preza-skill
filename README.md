# fin-academy-preza — скилл презентаций школы «Финансовый директор | Мастер CFO»

Claude Code skill: вёрстка презентаций/эфиров в фирменном тёмно-лаймовом стиле
(HTML+CSS → PDF, 16:9) с авто-подбором качественных 3D-объектов.

## Установка (для команды)

1. Клонировать репозиторий в папку скиллов Claude Code:
   ```
   git clone git@github.com:vasilevanatali/fin-academy-preza.git \
     ~/.claude/skills/fin-academy-preza
   ```
   (или скачать ZIP и распаковать в `~/.claude/skills/fin-academy-preza`)
2. Перезапустить Claude Code — скилл появится в списке.
3. Готово. **Лаймовые презы собираются сразу, без ключей и без затрат** — библиотека
   из 16 объектов уже в репозитории (`assets/objects/`).

## Генерация новых 3D-объектов (бесплатно, без ключей)

Иконки генерятся через **бесплатный Pollinations.ai** (Flux). Ключи, токены, регистрация и оплата
НЕ нужны — клонируете репо и работаете. Объект рисуется на чёрном фоне, скрипт `assets/gen-3d.py`
сам убирает фон в прозрачность и запекает фирменное свечение + тень.

- Лаймовые презы — сразу из готовой библиотеки `assets/objects/`, генерить ничего не надо.
- Новый объект: `python3 gen-3d.py rocket` (или любой `<concept>` из библиотеки / своё слово).
- Другой бренд-цвет: `python3 gen-3d.py <concept> --color "vibrant blue (#3B82F6)"` (свечение из hex).
- Свой промпт: `python3 gen-3d.py --prompt "..." --out my.png`. Вся библиотека: `--all`.
- Если Pollinations не ответил с первого раза — повторите (можно другой `--seed`). Это бесплатный
  публичный сервис, иногда отвечает не сразу.

## Использование

В Claude Code: «свёрстай презентацию … в нашем стиле» (+ контент, + референс цвета).
Подробности — в `SKILL.md`, дизайн-система — в `references/design-system.md`,
готовые блоки — `assets/slide-templates.html`.

Смена цвета под референс — 3 шага (палитра `:root` + `make-bg.py` + `gen-3d.py --color`),
см. раздел в `SKILL.md`.

## Что внутри

- `SKILL.md` — инструкция для Claude.
- `references/` — спек дизайн-системы + эталонные обзоры.
- `assets/theme.css`, `fonts/`, `bg-*.webp` — тема, локальные шрифты, фоны.
- `assets/objects/` — библиотека 3D-объектов (лайм) + `manifest.json`.
- `assets/gen-3d.py`, `make-bg.py`, `make-pdf.sh` — генерация объектов, фонов, сборка PDF.
