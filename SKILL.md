# Fin-Academy Preza — фирменный стиль презентаций (v2)

Делаю презы школы в едином дизайнерском стиле: тёмный фон + кислотный лайм/мятная бирюза,
тяжёлые UPPERCASE-заголовки лаймом/бирюзой, градиентные «таблетки», карточки, нумерованные лаймовые кружки,
и **качественные 3D-объекты со свечением, подобранные по смыслу слайда**. Вывод — HTML+CSS,
рендер в PDF через headless Chrome. Грузится быстро, без мерцания.

## Когда применять

Любой запрос «сделай/свёрстай презентацию (эфир, деком, слайды)». Если есть **референс дизайна**
(скрин чужого слайда, мудборд, сайт, лого, картинка стиля) — берём с него ВЕСЬ визуальный язык:
палитру, фон (тёмный/светлый), шрифт, стиль иконок, настроение, плотность, а не только цвет.
Тёмно-лаймовый бренд школы — это ДЕФОЛТ только когда референса нет. Полный процесс — раздел
«Дизайн по референсу» ниже.

## Работа строго по ТЗ (без отсебятины)

Скилл отвечает за ДИЗАЙН и ВЁРСТКУ, не за выдумывание контента. Жёстко:

- Берём ровно тот текст, структуру и число слайдов, что в ТЗ. НЕ добавляем слайды, пункты, цифры,
  тезисы и «улучшения», которых не просили.
- Формулировки по смыслу не меняем (только чистка стиля через `stop-slop-ru`: штампы, тире, «не X а Y»).
- Не хватает данных (заголовок, подпись, число) — спросить или оставить явный плейсхолдер
  `[…]`, а не придумывать. Факты и цифры не выдумываем (проверка фактов — не задача скилла,
  контент у всех разный; ключевое здесь — дизайн).
- Когда ТЗ идёт «по слайдам» — править ровно те слайды, не трогать остальные.

## Файлы

- `references/design-system.md` — ПОЛНЫЙ спек (палитра, шрифты, сетка, компоненты, типы слайдов). Читать первым.
- `references/slide-layout-rules.md` — ЧЕКЛИСТ вёрстки слайдов (использование площади, переносы, выравнивание, что не обрезать/не оставлять пустым, обязательная проверка в рендере). Свод правок Натали — применять к каждому слайду.
- `assets/theme.css` — тема. Палитра — в блоке `:root`. Локальные шрифты (`fonts/`, `fonts.css`), запечённые фоны (`bg-corner.webp`, `bg-center.webp`).
- `assets/slide-templates.html` — рабочая галерея: пример каждого типа слайда (уже с 3D-объектами). Копировать блоки.
- `assets/gen-3d.py` — генератор 3D-объектов (бесплатный Pollinations.ai, без ключа; фон убирается в прозрачность, свечение/тень запекаются).
- `assets/palette.py` — анализ референса: на вход картинка стиля → фон, текст, 2 акцента и готовый `:root` для theme.css + команды. Для режима «дизайн по референсу».
- `assets/font-compare.py` — рендерит шрифты-кандидаты одним листом (кириллица+латиница) для сверки с референсом ГЛАЗАМИ перед установкой (опознать шрифт по картинке на 100% нельзя — выбираем из кандидатов, не угадываем).
- `assets/fetch-font.py` — скачать ВЫБРАННЫЙ шрифт с Google Fonts ЛОКАЛЬНО (woff2, лат+кир) и дописать `@font-face`. Бесплатно, без ключа.
- `assets/objects/` — библиотека готовых 3D-объектов + `manifest.json` (подбор по смыслу слайда).
- `assets/make-pdf.sh` — сборка HTML → PDF (headless Chrome).
- `assets/check.py` — АВТО-АУДИТ вёрстки: находит переполнение, пустой низ, разъехавшиеся заголовки, битые картинки, прозрачность (мерцание). Гонять перед сдачей до «0 косяков». Пороги настраиваются под свой деком (`--free-bottom`, `--free-ratio`, `--head-max-lines`, `--overflow`); вызывается автоматически из `make-pdf.sh`. Нужен `pip install playwright`.

## Как собрать новую презу

1. **Сначала разобрать ТЗ** (см. «Работа строго по ТЗ» ниже): что за слайды, какой текст, сколько. Прочитать `references/design-system.md`.
2. Папка деком: `<имя>/index.html` + рядом скопировать `theme.css`, `fonts.css`, `fonts/`, `bg-*.webp`, `objects/`.
3. Есть референс дизайна? См. раздел «Дизайн по референсу» (`palette.py` → `:root`, фон, шрифт, иконки под стиль референса). Нет референса — дефолтный тёмно-лайм.
4. Верстать слайды из блоков `slide-templates.html`. Заголовки UPPERCASE, переносы руками `<br>`, левое выравнивание; дивайдеры/оффер/финал — `.slide--center`.
5. **3D-объекты — обязательны** (преза должна быть сразу дизайнерской, без плейсхолдеров):
   - Для каждого смыслового слайда подобрать объект по `objects/manifest.json` (matching темы слайда по keywords).
   - Есть в библиотеке → вставить `<div class="obj-wrap"><img class="obj3d" src="objects/<key>.png"></div>`.
   - Нет подходящего → сгенерить: `python3 gen-3d.py "<concept>"` (или `--prompt "..."` для своего). Свечение/тень запекаются автоматически.
   - Под другой бренд-цвет: `python3 gen-3d.py <concept> --color "vibrant blue (#3B82F6)"`.
6. Скрины/мокапы/QR/фото — реальные PNG в `images/`, в `.card-white` или `.obj-wrap`.
7. **Текст — через скилл `stop-slop-ru`** (убрать AI-штампы, «не X, а Y», длинные тире). Контент строго из ТЗ, не дописывать своё.
8. **Авто-аудит вёрстки (обязательно):** `python3 check.py index.html`. Починить найденные косяки и
   гонять СНОВА — цикл «нашёл → починил → перепроверил», пока не будет «✓ Косяков не найдено».
9. PDF: `bash make-pdf.sh index.html <имя>.pdf`.
10. **Самопроверка глазами:** `pdftoppm -jpeg -r 96 <имя>.pdf /tmp/p` → посмотреть КАЖДЫЙ слайд.
    Что числа не видят: некрасивые переносы, наезды, «висячие» слова, баланс. **Контраст** —
    текст и плашки должны читаться (особенно на светлом фоне из референса: тёмные карточки и
    лаймовые плашки на светлом теряются, заменить на контрастные). Чинить и пересобирать.

## Дизайн по референсу (палитра, шрифт, иконки, настроение)

Скилл НЕ зациклен на тёмно-лайме. Есть референс — собираем презу В ЕГО СТИЛЕ. Тёмно-лаймовый
бренд = дефолт только когда референса нет. Порядок:

1. **Посмотреть глазами** (открыть картинку-референс): фон тёмный/светлый; шрифт (гротеск/засечки,
   жирный/тонкий, округлый/строгий); стиль графики (3D-объёмные / плоские flat / линейные outline /
   эмодзи / фото); настроение (минимализм, яркий, корпоративный, тех); плотность и сетка.
2. **Палитра автоматом:** `python3 palette.py <референс.png>` → фон, текст, 2 акцента + готовый блок
   `:root` и команды. Вставить выданное в `:root` `theme.css`.
3. **Фон:** `python3 make-bg.py "#АКЦЕНТ" "#ВТОРАЯ"` под новые цвета. Светлый референс — фон делаем
   светлым/чистым (свечение убрать или сделать едва заметным), текст тёмным.
4. **Иконки в стиле и цвете референса:** `python3 gen-3d.py <concept> --color "(#АКЦЕНТ)"`. Если стиль
   НЕ 3D-глянец (flat / line / эмодзи) — генерить через `--prompt` с описанием стиля референса
   («flat minimal icon», «thin line icon») или взять готовые иконки нужного стиля. Класть в
   `<имя>/objects/`, мастер-лайм-библиотеку не затирать.
5. **Шрифтовая пара с референса (подобрать → СВЕРИТЬ глазами → подключить).** Опознать шрифт по
   картинке на 100% нельзя, поэтому не угадываем вслепую, а выбираем из кандидатов по рендеру:
   - Определить ДВА шрифта: **заголовочный** и **текстовый**. По картинке классифицировать —
     гротеск / с засечками / моноширинный / дисплейный; жирность; характер (геометрический,
     гуманистический, округлый, конденсированный).
   - Назвать 3-5 БЛИЗКИХ кандидатов с Google Fonts (Montserrat, Inter, Manrope, Unbounded, Onest,
     Golos Text, Playfair Display, Jost, Raleway и т.п.) и отрисовать их одним листом:
     ```bash
     python3 font-compare.py "Montserrat,Manrope,Unbounded,Onest" --out fonts-compare.png
     ```
   - Открыть `fonts-compare.png` РЯДОМ с референсом и выбрать пару, реально совпадающую по форме
     букв (а не по названию). Заголовок и текст сверять отдельно.
   - Поставить выбранное ЛОКАЛЬНО (чтобы PDF не мерцал, НЕ по сети):
     ```bash
     python3 fetch-font.py "<Заголовочный>" --weights 700,800,900
     python3 fetch-font.py "<Текстовый>"   --weights 400,500,600
     ```
     (если заголовок и текст — один шрифт разных весов, запустить один раз со всеми весами).
   - В `theme.css` прописать `font-family`: заголовкам — заголовочный, тексту/`body` — текстовый.
6. Дальше верстать как обычно (типы слайдов + чеклист `references/slide-layout-rules.md`). Компоновка
   та же, меняется только визуальный язык.

Под цвет меняем ВСЕ три уровня (палитра + фон + иконки), иначе рассинхрон (напр. синие иконки с
зелёным нимбом). Светлый референс: лаймовые плашки и тёмные карточки рассчитаны на тёмный фон — на
светлом заменить на контрастные (тёмный текст, светлые карточки с тенью). Контраст проверять в рендере.

## Производительность (почему быстро и без мерцания)

- Шрифт Montserrat — локально (`fonts/`), не с Google Fonts → нет FOUT/мерцания.
- Фон — заранее запечённый webp (свечение+контур+виньетка), не тяжёлый живой CSS.
- Свечение/тень 3D-объектов ЗАПЕЧЕНЫ в PNG (gen-3d.py), без CSS-фильтра → Chrome НЕ растрирует страницы, PDF лёгкий. **Не вешать `filter: drop-shadow` на объекты** — это раздувает PDF ×2 и даёт мерцание.
- Объекты ужимаются до ~720px и оптимизируются автоматически.

## Жёсткие правила стиля

- Тёмный фон + лёгкое зелёное свечение в углу. Текст белый/лайм.
- Заголовки — Montserrat 800, UPPERCASE, СПЛОШНЫМ цветом (лайм / бирюза / белый). НЕ градиент-в-тексте: `background-clip:text` в headless-Chrome даёт линию-рамку по краю блока в PDF (тянется через весь слайд). То же для крупных цифр. Градиент — только на заливках фигур (pill, иконки, кружки).
- «Таблетка» (`.pill`) — маркер категорий/подзаголовков/модулей. Система good (лайм-кружок) / bad (красный «×»).
- 3D-объекты — глянцевые, объёмные, трендовые, НЕ плоские. Всегда со свечением (запечено).
- **Красивая вёрстка текста — обязательно.** Никаких висячих слов (одно слово на отдельной последней строке, как «Qwen.» уехавшая вниз). Переносы строк контролировать руками (`<br>`), неразрывные связки — через `&nbsp;` (напр. `и&nbsp;Qwen`). В теме включены `text-wrap: balance` (заголовки) и `text-wrap: pretty` (текст) как страховка, но всё равно ГЛАЗАМИ проверять каждый слайд в рендере и при кривом переносе — править (ручной `<br>`, шире карточка, чуть меньше кегль). Текст должен ложиться сбалансированно.
- Без эмодзи в слайдах (если не попросят), без длинных тире — по правилам стиля Натали.
- **Площадь слайда использовать полностью.** Запрещено: текст сверху + пустой низ. Контент центрировать по вертикали (`.slide{justify-content:center}`), при избытке воздуха — наполнять (крупнее, картинки, плашка-вывод). Ничего не должно вылезать за край или обрезаться снизу. Полный чеклист (выравнивание сумм/галочек, badge абсолютом, ужатие картинок, проверка overflow/underflow в рендере) — `references/slide-layout-rules.md`. Применять к каждому слайду.

## Движки/доступы

- 3D-объекты: генерятся **бесплатно через Pollinations.ai**, `assets/gen-3d.py`. Ключи, токены,
  регистрация и прокси НЕ нужны — скилл можно отдать команде как есть. Два движка (flux→turbo) и
  авто-ретраи: если сервис не ответил или отдал мусор, скрипт сам пробует снова и переключает движок
  (раньше приходилось повторять вручную). Объект рисуется на чёрном фоне, скрипт сам убирает фон в
  прозрачность по яркости и запекает фирменное свечение + тень.
- Использование: `python3 gen-3d.py rocket` (из библиотеки), `python3 gen-3d.py <concept> --color "vibrant blue (#3B82F6)"`
  (свой цвет, свечение берётся из hex), `python3 gen-3d.py --prompt "свой промпт" --out my.png`, `--all` (вся библиотека).
  Совсем не отдаёт — позже или больше попыток `--retries 5`.
- Полностью бесплатно. Эталон стиля снят с деком «Готовые промпты в DeepSeek и Qwen».
